# FEAT-AIRDROMES-RUNTIME-SOURCE — Airdrome table from runtime dumps

Status: ✅ done

## Problem

`airdromes.yaml` (the airdrome name→id table used to resolve `warehouses` airfields
and to validate QRA `airport_link`) was generated by scraping each terrain's
`Beacons.lua`. Two defects:

1. **Wrong names.** The scraper took *beacon* `display_name`s (VOR/NDB callsigns,
   often a nearby town) and mapped them to the closest airfield id — e.g. `ABYAD: 7`
   where airfield 7 is Damascus. The committed names were beacon labels, not airbase
   names, so they rarely matched what `Airbase.getByName` / `airport_link` expects.
2. **Missing airfields.** Any airfield without a beacon was absent entirely.

Consequence (reported by a mission maker on Syria): the build validator rejected
valid `airport_link` values — Tiyas, Marj Ruhayyil, Al-Dumayr, Al Qusayr, Tha'lah,
Abu al-Duhur — as "unknown airfield on this theatre", though all exist in DCS.

## Decision (validated with David)

The **only** authoritative source for the exact name a mission uses is the DCS
runtime: `Airbase:getName()`. So the table is now sourced from **runtime dumps**
captured in-game via the VEAF dcs-bridge (`world.getAirbases()`, category
`AIRDROME`), committed per theatre as `veaf_build/dcs_data/airdrome_dumps/<Theatre>.tsv`.

- **Include everything** — real airfields *and* terrain helipads (all valid `Airbase`
  objects with a warehouse, usable for spawns/QRAs). No ATC/beacon filtering.
- `Beacons.lua` (and any `radio.lua` cross-check) is dropped for airdromes.
- `generate` **merges** dumps into the YAML: a dumped theatre is fully regenerated,
  an un-dumped theatre is preserved (theatres migrate lot-by-lot).
- `--airdromes` no longer needs `--dcs-path`.

## Captured in this lot (7 theatres, 657 airbases)

Caucasus (21), GermanyCW (227), MarianaIslands (8), Normandy (90), PersianGulf (30),
SinaiMap (56), Syria (225) — all via the kit, David running the missions.

Collateral finding: the retired scraper keyed theatres by **terrain folder**, leaving
stale `Sinai` / `GermanyColdWar` entries that duplicate the canonical `SinaiMap` /
`GermanyCW`. `generate` now drops a legacy key once its canonical theatre is captured.
