# FEAT-CHERRY-PORTABLE-KIT — Cherry Studio shipped preconfigured, with its data next to the executable

Status: ⬜ ready

Asked by David on 2026-11-27: someone who installs the kit should receive Cherry with the two VEAF assistants (missions, linked to the MCP; chatbot, knowledge base only) already configured. The current plan (FEAT-CHERRY-AI-SETUP) leaves one manual step: restoring the starting backup inside Cherry, then `ai-setup` fixes the server path.
The Cherry study read, in the code of tag `v2.2.3`, that a portable build keeps its data in `<exe folder>\data`. If that holds, a kit that ships Cherry portable with its data folder filled needs no restore and writes into no existing installation.
One ticket, a study. Nothing is built before its verdict.
