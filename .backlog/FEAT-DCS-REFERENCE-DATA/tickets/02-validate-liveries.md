# FEAT-DCS-REFERENCE-DATA-02 — validate liveries against the reference

Status: ⬜ ready
Type: feat
Files: `veaf_build/dcs_data/`, a new `veaf_libs/data/liveries.yaml`, `veaf_mission_mcp/set_unit_properties.py`, `veaf_mission_mcp/add_air_group.py`, `veaf_mission_mcp/actions.py`, tests

## What

Ship the stock liveries per unit type with their allowed countries, and use them in the MCP:

- warn when a livery id is unknown for the unit's type, or not allowed for its country;
- offer a `list_liveries(type, country)` read-only action.

## Why

Today the livery is "NOT validated": DCS shows the default skin for an unknown id, without a word.

## Constraint

The reference only knows the **stock** liveries. A squadron or mod skin installed on the server is legitimate and absent from it, so an unknown id is a **warning**, never a refusal.

## Done when

- `liveries.yaml` is generated by `update-dcs-data` from the pinned reference.
- `set_unit_properties` and `add_air_group` warn on an unknown or disallowed livery, and still write it.
- `list_liveries` documented in the MCP action catalogue (FR + EN).
