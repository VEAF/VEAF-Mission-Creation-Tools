# 08 — Weapon ranges in the unit database

Status: ✅ done

Files: `veaf_build` (`update-dcs-data`), `veaf_libs/data/dcsUnits.yaml`, `veaf_mission_mcp/oracle.py` (`list_unit_types`), tests.

## What happened

The Open Training prompt (4.5, 4.7) wants every permanent battery and every active zone's SAMs measured
against the enemy bases with slots, with a sourced or measured range. `dcsUnits.yaml` carries no range. The
Syria mission took them from DCS's own `ThreatRange` in a local dump of the unit database
(`db.Units.lua`, 2025-11-16) — the values the Mission Editor draws its range circles from: Patriot 100 km,
S-300PS 120 km, Buk 50 km, Kub 25 km…

## Done when

- `dcsUnits.yaml` carries `threat_range_m` (and `detection_range_m`) for every unit whose datamine entry has
  one, regenerated by `veaf-build update-dcs-data`.
- `list_unit_types` returns them.
- Test: a SAM launcher and a radar of the generated file carry the datamine's values.
