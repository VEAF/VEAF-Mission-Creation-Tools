# Backlog — VEAF Mission Creation Tools v6

Per-lot backlog. Every lot on disk is a directory `.backlog/<LOT-ID>/` and appears in exactly one
of the three indexes below, the one its `Status:` belongs to, as a short paragraph. Completed lots
are compacted into `.backlog/archive/<LOT-ID>.md` three days after closing. Sequencing lives in
[ROADMAP](../ROADMAP.md); the indexes are the source of truth for **scope and status**.

## Legend

- **Status**: ⬜ ready · 🔄 in-progress · 🧑 waiting-human · ⏸ paused · ✅ done · 🚫 wontfix
- ⏸ **paused** is *deliberately parked*, not blocked: unlike 🧑 nothing is expected of
  anyone, and unlike ⬜ an agent should not pick it up. See
  [`docs/agents/triage-labels.md`](../docs/agents/triage-labels.md).
