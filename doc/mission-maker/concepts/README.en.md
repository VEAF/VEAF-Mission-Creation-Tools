# The cards — one concept, one page

Ten short pages. Each answers "how do I write **this** one thing?", with the smallest example that
works, one gotcha, and a link to the reference for the rest.

They are not chapters to read in order. If you are new to VMCT, start with
[the map](../DISCOVER.en.md) or [the tutorial](../TUTORIAL.en.md); the cards are what you reopen
afterwards, one at a time.
