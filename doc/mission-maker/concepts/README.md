# Les fiches — un concept, une page

Dix fiches courtes. Chacune répond à « comment j'écris **cette** chose ? », avec le plus petit
exemple qui marche, un piège, et un lien vers la référence pour le reste.

Ce ne sont pas des chapitres à lire dans l'ordre. Si vous découvrez VMCT, commencez par
[la carte](../DISCOVER.md) ou par [le tutoriel](../TUTORIAL.md) ; les fiches sont ce que vous
rouvrez ensuite, une par une.
