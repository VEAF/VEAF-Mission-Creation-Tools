# VEAF Mission Creation Tools — v6 Restart Plan (2026-05-16)

## Context

The project has been in active development on branch `develop/v6-new-build-system` (renamed **`develop-v6`**) since September 2025. v6 introduces a redesigned build system, modular Python injectors (11 CLI commands), and a complete Lua test infrastructure (~915 tests). ## v6 Goals

1. **Quality** — Python quality gate (ruff + mypy + pytest) enforced locally and in CI
2. **UX** — InquirerPy interactive mode when `veaf-tools` is launched with no arguments, user preference persistence
3. **Lua runtime** — Centralized configuration system (`veaf.config` per module + `missionconfig.lua`)
4. **Build** — Embed module list in the exe, centralized `~/.veaf/` directory, version check on startup
5. **Release** — Squash merge to `master`, publish v6.1.0

## Git Flow

```
master          ← v5 stable (do not touch except urgent fixes)
  └─ develop-v6 ← v6 integration branch
       ├─ feature/infra-poetry-quality-gate
       ├─ feature/cli-improvements
       ├─ feature/tui-interactive
       └─ feature/lua-config-system
```

- `feature/*` → PR → `develop-v6`
- Urgent v5 fixes → `fix/*` from `master`, PR → `master`
- v6 release → squash merge `develop-v6` → `master`, tag `v6.1.0`

---

## Quality Gate

Must pass before every commit on a `feature/*` branch:

```powershell
poetry run ruff check src/python
poetry run ruff format --check src/python
poetry run mypy src/python
poetry run pytest
.\test\lua\run_tests.ps1
```
