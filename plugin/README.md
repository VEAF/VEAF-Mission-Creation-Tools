# Claude plugin assets

Assets for the Claude plugin that wraps this repo's `veaf-mission-mcp` server (the "hands/eyes")
with authoring skills (the "brain"). They are **versioned here, next to the MCP server they
accompany**, and bundled/referenced at packaging time by the separate
[`bfr-claude-plugins`](https://github.com/Bullseye-Francophone/bfr-claude-plugins) marketplace
repo — packaging itself is out of scope of this repo (see
`.backlog/FEAT-MCP-MISSION-EDITOR/PRD.md`).

- `skills/veaf-mission-authoring/` — how to author VEAF missions correctly through the MCP
  (naming conventions, combat-zone vs QRA group models, always consulting the oracle actions).
