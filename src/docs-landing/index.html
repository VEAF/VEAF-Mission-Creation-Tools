About

VEAF Mission Creation Tools is a hybrid Lua + Python system for designing and running dynamic DCS World missions.

  • Runtime Lua scripts — spawning, asset management, radio menus, AI combat zones, QRA, and more
  • Python CLI tools — weather injection, waypoints, aircraft loadouts, mission file manipulation
  • Open-source — MIT-licensed, contributions welcome
